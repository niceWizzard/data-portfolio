# Regional Family Income and Inequality Analysis (FIES 2023)

## Data Source & Methodology

The dataset was sourced from the **2024 Population and Vital Statistics dataset** published by the **Philippine Statistics Authority (PSA)** via [OpenSTAT](https://openstat.psa.gov.ph/PXWeb/pxweb/en/DB/DB__1A__VS__BI/0031A1ABIC0.px/?rxid=7b9a5b53-a963-49ed-a891-725fb49b9971).


### Data Processing

Data cleaning, transformation, and reconciliation were handled in PowerBI using **Power Query**:
* Standardized province and HUC identifiers across both rows
* Cleaned up geographic names (Capitalization, Trimming, etc.)
